# Biblioteca de prompts — Smart TV for Windows / Smart TV OS

Esta pasta reúne **prompts de referência para continuidade do desenvolvimento com assistentes de IA**. Eles foram organizados a partir das decisões e especificações documentadas no repositório; não são uma transcrição literal de conversas anteriores.

## Como usar

1. Leia primeiro `00-contexto-e-regras.md`.
2. Escolha o prompt específico da tarefa.
3. Anexe ou indique os arquivos relevantes do repositório.
4. Peça ao assistente para inspecionar a implementação existente antes de propor alterações.
5. Exija testes, documentação e uma lista honesta do que foi ou não validado.

## Regra de ouro

Não transformar requisitos planejados em funcionalidades anunciadas como prontas. Toda afirmação de compatibilidade deve indicar o ambiente e o teste que a comprovam. A documentação de estado real do produto prevalece sobre qualquer prompt.
